5 · Who does what

The model asks. The loop acts.

The model

  • Reads tool names + descriptions + schemas
  • Chooses tools and inputs
  • Decides when it's done
  • Remembers nothing between requests

Your loop

  • Holds the history and resends it
  • Runs the tools, inside labs/01-messages/
  • Turns errors into results
  • Enforces the step cap
